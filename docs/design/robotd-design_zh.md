# `robotd`：控制循环

`robotd` 拥有机器人最重要的实时路径：读取传感器、构造观测、运行策略、计算关节目标，
经过安全处理后写入电机总线。

## 控制循环

- 控制频率目标为 50 Hz。
- 输入包括 IMU、关节反馈、游戏手柄意图、ToF 和电池状态。
- 策略输出经过形状校验、关节限幅、速度限制和跌倒保护。
- 电机总线由 `robotd` 独占，其他服务通过 IPC 请求动作。
- 控制循环异常时，机器人应进入安全状态并在健康报告中说明原因。

本文还覆盖运动学模型、策略槽位、技能、姿态、跌倒恢复、声音、theremin、chorale
和配置参数。参数默认值与校验定义在 `robotd-params` 中。
