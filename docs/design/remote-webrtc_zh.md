# WebRTC：会话、信令和控制通道

本文说明手机、浏览器或服务端程序如何通过 WebRTC 观察和控制机器人。设计首先覆盖
局域网内的本地信令，远程访问则在其前面增加代理或 rendezvous 服务。

## 会话组成

- 视频轨道传输摄像头画面。
- 音频轨道传输麦克风或机器人声音。
- 数据通道承载 JSON-RPC 控制请求和状态事件。
- 信令负责交换 SDP 和 ICE 信息，不直接执行机器人操作。
- 每个会话都必须经过认证、权限检查和资源清理。

机器人断开、浏览器关闭或控制权限撤销时，会话应及时关闭；控制通道不能绕过本地
安全限制。网页客户端实现见[WebRTC 控制台](webrtc-console_zh.md)。
