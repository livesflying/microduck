# 启动恢复网络

当机器人启动的版本无法正常拉起守护进程时，启动恢复网络负责把机器人恢复到已知可用
的 `golden` 版本。

## 机制

- 启动检查在规定的时间窗口内观察关键 systemd 服务。
- 只有满足故障条件时才触发恢复，避免正常启动被误判。
- `golden` 符号链接指向经过验证的稳定版本。
- 恢复操作带有循环保护，避免两个坏版本之间反复切换。
- 恢复过程会留下记录，方便在下一次启动时判断是否已经处理过。
