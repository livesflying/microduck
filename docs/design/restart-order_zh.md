# 重启顺序

本文是所有会移动 `current` 符号链接的更新路径和系统启动路径的权威重启顺序。
顺序错误会导致服务继续运行旧二进制，或让健康检查观察到混合版本。

## 规则

1. 更新器先完成签名、哈希和兼容性校验。
2. 安装新版本并原子切换 `current`。
3. 按依赖顺序重启使用新版本的服务。
4. 等待服务重新建立 IPC、硬件和媒体资源。
5. 由健康检查确认机器人可用；失败时回滚并再次按顺序启动。

启动恢复网络会在这个顺序中读取启动记录并决定是否回到 `golden`。具体函数和每条
路径的步骤以英文源文档为准。

英文源文档：[restart-order.md](restart-order.md)。
