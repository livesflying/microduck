# 机器人更新系统设计

`updaterd` 负责将已签名版本安全地安装到机器人。更新流程必须保证版本来源可信、
文件完整、机器人仍可恢复，并且安装失败不会留下不可启动状态。

## 更新流程

1. 获取版本清单和更新产物。
2. 校验版本、平台兼容性、哈希和签名。
3. 在独立目录解包并执行安装前钩子。
4. 原子切换 `current`，按规定顺序重启服务。
5. 执行健康检查；失败时自动回滚到前一版本。
6. 记录完整 transcript，方便离线排障。

版本存储保留 `golden` 和可回滚版本。开发板使用单独的开发密钥，客户机器人默认拒绝
开发构建。更新机制与[启动恢复网络](boot-recovery-net_zh.md)和[重启顺序](restart-order_zh.md)
共同保证设备可恢复。
