# WebRTC 客户端：从测试页面到机器人控制台

本文描述运行在机器人上的 WebRTC 网页客户端。页面由机器人提供，不依赖开发机上的
临时 `python3` 静态服务器，并通过蓝牙广播的地址发现机器人。

## 客户端职责

- 建立信令和 WebRTC 会话。
- 展示视频、音频、连接状态和机器人健康信息。
- 使用允许的控制 RPC 驱动机器人。
- 在断线、权限不足和服务不可用时显示明确状态。
- 不在浏览器中复制机器人端的安全逻辑，控制请求仍由服务端校验。

传输层设计见[远程 WebRTC](remote-webrtc_zh.md)，整体服务关系见[系统架构](architecture_zh.md)。
