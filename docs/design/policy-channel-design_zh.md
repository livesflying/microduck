# 策略通道设计：来自 Hub 的策略

本文说明机器人如何获取、校验、安装和运行 ONNX 运动策略，以及如何尝试社区策略。
策略可以独立于守护进程发布，不必每次更换动作都发布完整 daemon。

## 策略类型

- 官方策略集：机器人默认使用的步态、站立和动作。
- 社区策略：用户从 Hub 指定加载的策略。
- 技能：在当前步态旁边按命令或手柄按键触发的一次性动作。

## 安全边界

机器人会检查输入输出形状、清单兼容性和运行状态。策略本身不是可信代码，安全性来自
关节限幅、跌倒保护、命令形状检查和加载失败时保留旧策略。第一次运行陌生策略时，
应让机器人处于安全支撑状态。

`reset` 会删除自定义覆盖并回到当前版本提供的官方策略。策略清单字段见
[策略清单规范](../policy-manifest_zh.md)。
