# 策略清单规范

本文说明与 Microduck `.onnx` 文件一起发布的 `manifest.json` 格式（schema 2）。
它同时支持单策略仓库和官方策略集合，两者使用同一套字段和校验规则。

## 主要内容

- `file`：策略文件名。
- `kind`：策略类型，例如持续运行的策略或有时长的动作策略。
- `duration_s`：一次性动作的持续时间。
- `command`：策略需要的命令编码和参数。
- 兼容性、输入输出形状和版本约束。

发布策略前，应保证清单中的文件存在、字段符合 schema，并能被目标版本的 `robotd`
加载。机器人会在下载或加载阶段检查清单，拒绝不兼容的策略。
