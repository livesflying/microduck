# 自主行为栈

本文是自主行为功能的设计草稿和想法收集区。当前运行时还缺少一个统一的
`autonomous` 行为栈，因此这里记录需要补齐的接口和已有 theremin、chorale 工作可以
复用的思路。

## 待解决问题

- 行为如何选择和切换策略。
- 行为如何表达优先级、持续时间和取消条件。
- 自主行为如何与手柄、远程控制和安全状态共存。
- 行为如何使用声音、视觉、ToF 和电池等感知输入。
- 如何测试行为不会绕过 `robotd` 的安全边界。

本文不是已批准的设计；形成稳定机制后，应迁移到正式设计文档。
