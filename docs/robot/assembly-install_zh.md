# 舵机安装与初始姿态

本文定义当前 microduck 结构的舵机安装位置，并区分三个不能混淆的概念：

- **舵机中心位置**：STS3215 的位置值 `2048`，约等于 `0°`。
- **机械零位**：安装舵盘时选择的机械方向。
- **机器人初始姿态**：所有舵机安装完成后，执行 `robotctl robot init` 进入的软件 home pose。

软件初始姿态定义在
[`duck-control/src/model.rs`](../../duck-control/src/model.rs) 的 `DEFAULT_POSITION` 中。
不要用软件偏移去掩盖舵盘少装半个齿的问题，应优先修正机械安装。

## 安全要求

1. 安装或调整舵盘时关闭舵机扭矩。
2. 执行 `robotctl robot init` 前，将机器人固定在支架上。
3. 单舵机调试阶段不要开启行走策略。
4. 接入完整舵机链之前，先逐个舵机测试。
5. 如果关节碰到机械限位，立即拆下舵盘或断开连杆。

## 各舵机安装方向

以下方向均以**机器人自身视角**为准：机器人面向前方时，机器人的左侧和右侧就是左、右腿；
不是站在机器人前面观察时的左右反转。

安装时先让舵机处于 `2048`，再安装舵盘和连杆。舵机的输出轴必须与下表对应的关节轴重合，
舵机壳体不能为了“让线缆朝同一边”而翻转到相反姿态。左右腿结构需要镜像安装。

| 舵机 | 关节轴和安装基准 | 初始姿态检查 |
|---|---|---|
| ID 20 左髋偏航 | 绕竖直轴旋转；舵机安装在左髋最上层，输出轴朝向髋部转轴 | 左腿相对躯干处于正中，不明显向前或向后扭转 |
| ID 21 左髋横滚 | 绕左右方向的横滚轴；左侧安装方向与右髋镜像 | 左腿不向外塌或向躯干倾斜，保持 `-5°` |
| ID 22 左髋俯仰 | 绕前后方向的髋部俯仰轴；连杆位于身体前后矢状面 | 左大腿按 `-26.24°` 向软件定义方向倾斜 |
| ID 23 左膝 | 膝关节弯曲轴；膝盖的弯曲方向应朝身体后侧，不得反向折叠 | 左腿接近伸直，目标约 `-0.28°` |
| ID 24 左踝 | 脚踝俯仰轴；脚底与水平面平行 | 左脚掌落在同一水平面，目标约 `+25.95°` |
| ID 30 颈部俯仰 | 绕颈部左右方向的俯仰轴 | 颈部向软件定义方向抬起约 `+20°` |
| ID 31 头部俯仰 | 绕头部俯仰轴，安装后头部可上下点头 | 头部约 `+20°`，摄像头方向保持可用 |
| ID 32 头部偏航 | 绕头部竖直轴，安装后头部可左右转动 | `0°` 时脸和摄像头正对机器人前方 |
| ID 33 头部横滚 | 绕头部前后方向轴，安装后头部可左右侧倾 | `0°` 时头部保持水平，不左右歪斜 |
| ID 34 嘴部 | 绕嘴部铰链轴；连杆不能顶住上下唇壳 | `0°` 为模型中性位置，确认闭合限位不会卡死 |
| ID 10 右髋偏航 | 与左髋偏航左右镜像；不要只复制左侧舵盘角度 | 右腿相对躯干处于正中，不明显扭转 |
| ID 11 右髋横滚 | 与左髋横滚左右镜像 | 右腿不向外塌或向躯干倾斜，保持 `+5°` |
| ID 12 右髋俯仰 | 与左髋俯仰左右镜像 | 右大腿按 `+26.24°` 向软件定义方向倾斜 |
| ID 13 右膝 | 与左膝左右镜像；膝盖弯曲方向仍朝身体后侧 | 右腿接近伸直，目标约 `+0.28°` |
| ID 14 右踝 | 与左踝左右镜像 | 右脚掌与左脚掌同高、同向，目标约 `-25.95°` |

### 各转轴的明确方向

项目坐标系定义如下：

- `+X`：机器人正前方；
- `+Y`：机器人左侧；
- `+Z`：机器人上方；
- 正角度遵循右手定则，拇指指向表中的正轴方向。

下表把**机械转轴轴线**和**舵机数值方向**分开列出。机械转轴本身是一条直线，
没有物理上的“正端”和“负端”。所有 Feetech 舵机在本项目中的数值方向都是：

```text
2048 -> 更大的位置值 = 舵机软件角度增加
2048 -> 更小的位置值 = 舵机软件角度减小
```

左右舵机是对置安装的，因此同样的数值变化在左右两边会产生镜像的机械动作。
不要因为左右两边的机构动作相反，就把其中一个舵机的软件数值方向反过来。
例如右髋俯仰的初始值是 `2347`，左髋俯仰的初始值是 `1749`；这正是左右对置
安装后的镜像目标，而不是软件方向不一致。

| 舵机 | 关节 | 机械转轴轴线 | 舵机数值增加方向 | 模型坐标中的正转轴 |
|---:|---|---|---|---|
| 20 | 左髋偏航 `left_hip_yaw` | 竖直方向 `Z` | 增大为正 | `-Z` |
| 21 | 左髋横滚 `left_hip_roll` | 前后方向 `X` | 增大为正 | `+X` |
| 22 | 左髋俯仰 `left_hip_pitch` | 左右方向 `Y` | 增大为正 | `+Y` |
| 23 | 左膝 `left_knee` | 左右方向 `Y` | 增大为正 | `-Y` |
| 24 | 左踝 `left_ankle` | 左右方向 `Y` | 增大为正 | `+Y` |
| 30 | 颈部俯仰 `neck_pitch` | 左右方向 `Y` | 增大为正 | `-Y` |
| 31 | 头部俯仰 `head_pitch` | 左右方向 `Y` | 增大为正 | `+Y` |
| 32 | 头部偏航 `head_yaw` | 竖直方向 `Z` | 增大为正 | `+Z` |
| 33 | 头部横滚 `head_roll` | 前后方向 `X` | 增大为正 | `-X` |
| 34 | 嘴部 `mouth` | 当前 MJCF 未定义，按实际嘴部铰链中心线确认 | 增大为正 | 未定义 |
| 10 | 右髋偏航 `right_hip_yaw` | 竖直方向 `Z` | 增大为正 | `-Z` |
| 11 | 右髋横滚 `right_hip_roll` | 前后方向 `X` | 增大为正 | `+X` |
| 12 | 右髋俯仰 `right_hip_pitch` | 左右方向 `Y` | 增大为正 | `-Y` |
| 13 | 右膝 `right_knee` | 左右方向 `Y` | 增大为正 | `+Y` |
| 14 | 右踝 `right_ankle` | 左右方向 `Y` | 增大为正 | `-Y` |

机械轴线用于安装舵机：髋部俯仰、膝盖和脚踝都应安装在同一类左右方向的平行轴线上。
Feetech 数值方向由代码中的 `angle_from_raw()` 定义，位置值增加就是软件角度增加。
模型坐标中的正转轴由 `kinematics/assets/alpha/robot_walk.xml` 中各关节的本地
`axis="0 0 1"` 转换到躯干坐标系得到。上游关节转动后，下游关节的实际轴线会随机构一起转动；
安装检查使用的是初始姿态附近的方向。

```text
             +Z 上
               |
               |
       +Y 左 <-+-> 右侧 -Y
               |
             +X 前

左髋 yaw    -Z       右髋 yaw    -Z
左髋 roll   +X       右髋 roll   +X
左髋 pitch  +Y       右髋 pitch  -Y
左膝        -Y       右膝        +Y
左踝        +Y       右踝        -Y
颈 pitch    -Y       头 pitch    +Y
头 yaw      +Z       头 roll     -X
```

这里的“机械轴线方向”用于判断舵机是否与铰链同轴；“增大为正”是所有 Feetech 舵机共同的
数值约定，不等同于从机器人前方观察时的“顺时针”或“逆时针”。对于髋部俯仰、膝盖和脚踝，
机械轴线相同；左右对置安装后，增大同样的舵机数值会产生镜像机械动作。
由于舵盘每个齿位是离散的，最终应以初始姿态和小角度动作验证为准。

### 小角度确认每个方向

每次只连接一个舵机，并保持机器人支撑在支架上：

1. 关闭策略，扭矩关闭时把舵盘安装到最接近的中性方向。
2. 设定目标位置 `2048`，确认舵盘和连杆不碰撞。
3. 让目标位置增加约 `50` 个位置值，观察运动方向。
4. 让目标位置恢复 `2048`，再减少约 `50` 个位置值观察反方向。
5. 如果运动方向与期望的镜像机械动作相反，不要交换软件正负号；重新检查舵机是否左右装反、
   输出轴是否装在错误一侧，或舵盘是否安装在相反齿位。Feetech 数值方向固定为“增大为正”。

对左右腿，必须同时检查镜像关系：同一类关节的机械动作应当产生对称的腿部姿态，而不是
两条腿向同一侧偏。

## 机械安装步骤

### 1. 确认舵机中心

在舵机尚未接入连杆时：

1. 将目标位置设为 `2048`。
2. 确认舵盘可以自由转动，不会碰撞机身。
3. 在舵机输出轴和舵盘上做好方向标记。
4. 安装舵盘时保持扭矩关闭。

`2048` 是电气中心参考值，不代表每个关节最终都应停在 `0°`。

### 2. 安装舵盘和连杆

将舵盘安装在最接近目标机械方向的齿位上。拧紧螺丝前检查：

- 连杆没有预紧；
- 关节能通过计划的活动范围；
- 舵盘不会摩擦机身；
- 左右腿结构保持镜像；
- 线缆在两端位置都不会被拉紧。

### 3. 处理少半个舵齿

舵盘齿位是离散的。如果当前方向只差半个舵齿：

1. 先调整到最接近的可用齿位。
2. 保持连杆自然，不要用弯曲连杆来掩盖误差。
3. 检查关节活动范围的两端。
4. 不要直接增加软件偏移，除非已经完成关节标定，并将偏移作为模型变更记录。

正式装配应通过舵盘齿位或连杆长度调整，获得可重复的中性位置。未同步到训练模型的软件偏移会改变策略使用的坐标基准。

## 单舵机调试

单舵机测试时，可以使用当前 Feetech 配置：

```toml
[bus]
protocol = "feetech_scs"
feetech_ids = [1]

[policy]
enabled = false
```

当前 Feetech 后端会把配置列表中的第一个 ID 映射到第一个关节槽位。完整 15 个舵机应按关节顺序配置：

```toml
feetech_ids = [20, 21, 22, 23, 24, 30, 31, 32, 33, 34, 10, 11, 12, 13, 14]
```

首次转动前，确认目标位置在安全机械范围内。第一次应使用慢速，确认转动方向正确。单舵机验收至少包括：

- 舵机能在 1 Mbps 下响应；
- ID 配置正确；
- 增大目标值时转动方向符合预期；
- 位置反馈稳定；
- 没有撞限位或异常电流。

## 整机初始化

所有舵机安装完成并配置好总线后执行：

```bash
sudo robotctl robot init
```

`init` 会打开扭矩，并让所有已配置关节缓慢移动到软件初始姿态。由于所有关节都会运动，必须将机器人固定在支架上。确认姿态正确前保持策略关闭。

当前 Radxa ZERO 3 上的 I2C LSM6DSV16X 配置为：

```toml
imu = "i2c_lsm6dsv16x"
imu_i2c_bus = 4
imu_i2c_address = 106
```

日志中应能看到：

```text
LSM6DSV16X I2C IMU ready bus=4 address=0x6a
```

IMU 不参与舵盘机械对齐，但检查初始重力方向时，应将机器人放在水平支架上。

## 装配验收清单

- [ ] 舵机 ID 与配置中的关节顺序一致。
- [ ] 所有舵机均能在 1 Mbps 下响应。
- [ ] 安装舵盘前已确认舵机中心位置。
- [ ] 初始姿态下舵盘和连杆没有预紧。
- [ ] 左右腿保持镜像。
- [ ] 初始化过程中没有关节撞机械限位。
- [ ] 颈部和头部初始角度约为 `+20°`。
- [ ] IMU 在 I2C 地址 `0x6a` 返回 `WHO_AM_I=0x70`。
- [ ] 机械姿态确认前，策略保持关闭。
